Root Cause Channel: Privacy Policy

Root Cause Channel is a private tool used only by its owner to upload and manage videos on the owner's own YouTube channels.

What it accesses

With your permission, it uses the YouTube Data API and the YouTube Analytics API to upload videos, read your channel's videos, and read your channel's statistics.

How data is stored

Sign-in tokens and channel data are kept only on the owner's own computer. Nothing is sent to any other server, sold, or shared with anyone.

Removing access

You can remove the app's access at any time at myaccount.google.com/permissions.

Google API Services

Root Cause Channel's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Use the support email shown on the Google sign-in screen for this app.
